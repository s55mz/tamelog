# tamelog 作業内容ログ

## プロジェクト概要
家計管理アプリ「貯めログ」。React 19 + Vite フロント、Hono (Node.js) バックエンド、PostgreSQL + Prisma ORM。

---

## フェーズ8以前 (省略)
UI基盤、認証、記録・口座・目標・カテゴリ・家計簿・衝動買い防止リスト等の基本機能を実装。

---

## フェーズ9 セッション1 (2026-03-14)

### デザインリニューアル — TSUKUE デザインシステム
- ユーザー要求: 「AIが作ったみたい。クリエイティブデザイナーが作ったふうにして」
- `client/src/styles.css` を全面書き換え
  - カラー: 温かみのある和紙系 (`--bg: #F4F2ED`)、フォレストグリーンアクセント (`--amber: #1E6647`)
  - フォント: DM Mono (数字)、Outfit (見出し・ボタン)、Noto Sans JP (日本語)
  - サイドバー: 左ボーダーアクティブインジケーター、ドロップシャドウなし
  - 角丸縮小: よりエディトリアルなスタイル
- `client/index.html`: theme-color を `#F4F2ED` に変更

### 大規模機能追加

#### DBスキーマ変更 (`prisma/schema.prisma`)
- `DailyRecord` に `emotions String[] @default([])` と `recordedAt DateTime @default(now())` を追加
- `SystemConfig` に `openaiApiKey String?` を追加
- `AIAnalysis` に `version Int @default(1)` を追加、ユニーク制約を `(userId, targetMonth, version)` に変更
- `paydayOfMonth` のデフォルトを 25 に変更

#### サーバー変更
- `server/src/routes/records.ts`: emotions, recordedAt, categoryId フィルタ, all=true 対応
- `server/src/routes/admin.ts`: OpenAI APIキー管理 (GET/PUT /api/admin/config)
- `server/src/routes/ai.ts`: gpt-4o-mini, DB APIキー管理, チャット履歴, 月次分析 (月3回・バージョン管理)

#### クライアント変更
- `client/src/lib/format.ts`: formatDateTimeJP, getPeriodIdClient, listPeriods を追加
- `client/src/pages/UserSetupPage.tsx`: token未渡しバグ修正、給料日デフォルト25日、口座名placeholder

- `client/src/pages/ChatPage.tsx`: チャットバブルUI、タイピングインジケーター
- `client/src/pages/GoalsPage.tsx`: ヒーロー画像を横並び表示、サムネイル88px
- `client/src/pages/RecordPage.tsx`: モードボタン大型化、感情チップ追加
- `client/src/pages/LedgerPage.tsx`: 期間セレクタ、タブ(一覧/カレンダー)、カテゴリフィルタ

## フェーズ9 セッション2 (2026-03-14)

### バグ修正

| 症状 | 原因 | 修正 |
|------|------|------|
| /api/records 等が500エラー | DBマイグレーション未実行 | `prisma db push --accept-data-loss` 実行済 |
| apple-mobile-web-app-capable 警告 | 旧メタタグのみ | `mobile-web-app-capable` を追加 |
| 数字フォントが見づらい | DM Monoのみ指定 | システムフォント (ui-monospace, SF Mono等) にフォールバック追加 |

### 機能追加・改善

| 機能 | 変更ファイル | 内容 |
|------|------------|------|
| OCR | server/src/routes/ai.ts, RecordPage.tsx | POST /api/ocr: レシート画像→OpenAI Vision→JSON抽出→フォーム自動入力 |
| チャット履歴保存 | ChatPage.tsx | localStorageに最大100件保存、リロード後も残る |
| チャット入力固定 | ChatPage.tsx | position: fixed で画面下部に固定 |
| メニューをリスト化 | AppLayout.tsx, styles.css | モバイルシートメニューをタイル→縦リスト (.sheet-list-item) |
| 感情チップから絵文字削除 | RecordPage.tsx | テキストのみ: 嬉しい/衝動的/不安/必要/疲れた/後悔 |
| 記録フィールド整理 | RecordPage.tsx | 口座・日時・取引先を必須に。メモ→取引先にリネーム |
| 日時入力 | RecordPage.tsx | datetime-local で日付+時間を一括入力 |
| サーバーOCRルート登録 | server/src/index.ts | /api/ocr を登録 |

## コマンド

```bash
# フロント開発サーバー
cd client && npm run dev

# バックエンド開発サーバー
cd server && npm run dev

# 型チェック
cd client && npx tsc --noEmit
cd server && npx tsc --noEmit

# DBマイグレーション
npx prisma db push

# ビルド
cd client && npm run build
```
