# Phase 8 記録

更新日: 2026-03-13

## ステータス

- 完了

## 目的

- 更新後の `frame.md` を正として、画面遷移・共通レイアウト・主要画面構成を再設計する
- 既存デザインの延長ではなく、現行仕様との差分が大きい画面を中心に UI を作り直す

## 計画

- `frame.md` を基準に、現行ルーティングと不足画面の差分を洗い出す
- 共通ナビゲーションを `ホーム / 記録 / 家計簿 / もっと見る` ベースへ寄せる
- 不足している `/settings` を追加する
- `ホーム / 記録 / 目標 / 進捗 / 家計簿 / 口座 / 設定` の主要画面をワイヤーフレーム寄りに再構成する
- 型チェックとビルドで整合性を確認する

## 実行

- `frame.md` を読み直し、現行実装との差分を整理
- 共通レイアウトのナビゲーションを再構成
  - モバイル主タブを `ホーム / 記録 / 家計簿 / その他` に変更
  - サイドバーに `設定` を追加
- `/settings` ルートを追加
- `SettingsPage` を追加し、プロフィール更新 / 給料日設定 / カテゴリ一覧 / 通知設定の UI を実装
- `DashboardPage` に給料日バナーと衝動買いチェック導線を追加
- `RecordPage` を `frame.md` の入力導線に寄せて再構成
  - クイック入力カード
  - カテゴリチップ選択
  - テンキー風ボタン
- `GoalsPage` に詳細シート相当の詳細表示を追加
- `ProgressPage` に `概要 / シミュレーション / AI分析` タブを追加
- `LedgerPage` を収入 / 支出 / 貯金 / 移動の統合一覧に変更
- `AccountsPage` に総残高カードを追加し、一覧と追加フォームの階層を整理
- `npm run typecheck` と `npm run build` を実行

## 結果

- やったこと:
  - `frame.md` 準拠で共通ナビゲーションを再構成
  - `SettingsPage` と `/settings` を追加
  - `ホーム / 記録 / 目標 / 進捗 / 家計簿 / 口座 / 設定` を Phase 8 範囲として再構成
  - モバイルの主要導線を `ホーム / 記録 / 家計簿 / その他` に合わせた
  - 主要画面を `frame.md` のワイヤーフレーム寄りに更新
- 確認結果:
  - `npm run typecheck` 成功
  - `npm run build` 成功
- 残課題:
  - `settings` のカテゴリ CRUD と通知保存 API は未実装
  - `record` の本格テンキー入力や達成トーストは簡易版
  - `goals` の下部シート、`accounts` の編集 / 削除モーダル、`ledger` の削除操作は未実装
  - `frame.md` の全画面を完全一致で再現するには、まだ API と UI の追加実装が必要
