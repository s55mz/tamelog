# TameLog — 継続しやすいUX改善アイデア

更新日: 2026-03-21

---

## 現状の課題分析

### 記録フローの問題点

| 問題 | 詳細 |
|---|---|
| **入力ステップが多い** | 種別 → 金額 → 口座 → 取引先（必須）→ 日時 → カテゴリ → 保存 と工程が多い |
| **取引先が必須** | 「コンビニで何か買った」程度でも店名を打たないといけない |
| **保存後に家計簿へ飛ぶ** | 連続記録したいのに画面が変わってリズムが崩れる |
| **スクロールが多い** | キーパッド → 口座 → 取引先 → カテゴリ と縦に長い |
| **モード切り替えが4ボタン横並び** | 「支出」がデフォルトでないと毎回タップが必要 |

---

## 改善の方向性

**「10秒で1件記録できる」** を最優先ゴールに設定する。

```
現在: 記録する → 種別選択 → 金額入力 → 取引先入力 → カテゴリ選択 → 保存 → 家計簿
目標: ホーム → 金額入力 → 保存  （細かい情報は後で付け足せる）
```

## アイデア 1: クイックシート記録（最重要）

### 概要

ホーム画面の「記録する」ボタンをタップしたとき、新しいページに遷移するのではなく、**画面下からスライドアップするボトムシート**で入力させる。

### レイアウト案

```
┌─────────────────────────────┐
│ /// ドラッグハンドル          │
│                             │
│  [支出] [収入] [貯金] [移動]  │  ← 4タブ（支出がデフォルト）
│                             │
│  ¥ 1,200                    │  ← 大きな金額表示
│                             │
│  [1][2][3]                  │
│  [4][5][6]                  │
│  [7][8][9]                  │
│  [00][0][⌫]                 │
│                             │
│  取引先: セブン-イレブン ▼    │  ← 履歴サジェスト付き入力
│                             │
│  [食費][交通費][日用品]...    │  ← 前回使ったカテゴリを先頭に
│                             │
│  ┌──────────────────────┐   │
│  │    支出として保存      │   │
│  └──────────────────────┘   │
│                             │
│  + くわしく設定（口座・日時） │  ← 折りたたみ
└─────────────────────────────┘
```

### ポイント

- **取引先を任意に変更**: 省略可能にしてメモ欄として扱う
- **詳細設定は折りたたみ**: 口座・日時は「くわしく設定」で展開
- **保存後もシートが開いたまま**: 「保存しました ✓」とトーストが出て、金額がリセットされるだけ。連続記録しやすい
- **シートを閉じると家計簿または元の画面**: 強制遷移しない

## アイデア 2: 取引先の入力補助

### 概要

取引先フィールドに**過去の入力履歴をサジェスト**として表示し、選ぶだけで済むようにする。

### 仕様案

- 入力フォーカス時に直近10件のユニーク取引先をチップで表示
- 1文字打つとマッチするものだけ絞り込む
- チップをタップすると即座に入力される
- カテゴリも一緒に補完（「セブン-イレブン」を選んだら「食費」が自動選択）

```
取引先
[ セブン-イレブン         ]

━━ よく使う ━━
[セブン-イレブン] [カフェ] [スーパー] [電車] ...
```

## アイデア 3: 金額サジェスト

### 概要

キーパッドの上に**よく使う金額**をチップで表示する。

### 仕様案

- 過去の記録から頻出金額をランキング（上位5件）
- 種別ごとに別々に学習（支出の頻出 ≠ 収入の頻出）

```
よく使う金額
[¥150] [¥500] [¥1,200] [¥3,500] [¥10,000]
```

## アイデア 4: ホームの「今日の状況」をより明確に

### 概要

Hero カードに「今日まだ記録していない」状態がわかるインジケーターを追加する。

### 仕様案

```
┌─────────────────────────────┐
│ おはようございます          │
│                             │
│  口座の残高                 │
│  ¥ 234,500                  │
│                             │
│  今日の記録  │  今期の貯金   │
│  ─────────  │  ¥30,000     │
│  まだ記録なし│              │  ← 今日0件なら強調表示
└─────────────────────────────┘
```

- 今日すでに記録があれば「3件」と件数を表示
- 記録がない日は「まだ記録なし → 記録する」ボタンを薄く表示
- 習慣として認識しやすくなる

## アイデア 5: 記録後の継続フロー改善

### 現状の問題

保存すると `/ledger?periodId=...` に遷移してしまい、連続記録の流れが断ち切られる。

### 改善案

保存後の動作を3パターンから選べるようにする（設定で変更可）:

| パターン | 動作 |
|---|---|
| **連続記録モード（デフォルト）** | 画面をリセットして同じフォームを維持。トースト「保存しました」 |
| **確認モード** | 保存した内容のサマリーカードを一瞬表示してから戻る |
| **現在の動作** | 家計簿へ遷移 |

## アイデア 6: 記録ストリーク表示

### 概要

**何日連続で記録しているか**をホームに小さく表示する。記録する習慣を形成するための仕掛け。

### 仕様案

```
ホームヘッダーの右上アバターの近くに小さく:

  🔥 7日連続記録中

または、ヒーローカードの sub-stats に追加:
  今期の貯金 │ 目標進捗 │ 連続記録
  ¥30,000   │  47%    │  7日
```

- 当日中に1件でも記録があれば「継続」
- 3日・7日・30日などの節目でトーストを表示

## アイデア 7: 衝動買いフローをホームから直接

### 概要

現在「保留リスト」はその他シートの奥にある。衝動買いの気持ちが起きた瞬間に操作できるよう、ホームのクイックアクションに追加するか、記録フォームの「保留として記録」ボタンを設ける。

### 記録フォームへの統合案

保存ボタンの下に小さく:

```
[支出として保存]

または → [24時間保留にする]  ← 衝動かも？と思ったらこちら
```

## アイデア 8: カテゴリ選択の改善

### 現状

チップが横スクロールなしで折り返して並んでいる。カテゴリが多いと押しづらい。

### 改善案

- **上位3件を大きいチップで表示**、残りは「もっと見る」で展開
- 種別変更時にアニメーションでフェード切り替え
- 直近7日でもっとも使ったカテゴリを先頭に並べる

```
カテゴリ  （直近での使用順）
[食費 ●] [交通費] [日用品]  [もっと見る ▾]
```

## まず着手すべき3点

1. **取引先を任意に変更** (`required` を外すだけ) → すぐできる
2. **保存後に遷移しない** (navigate を削除してリセットのみ) → すぐできる
3. **クイックシート実装** → ボトムシートUIを作る

この3点だけでも「記録したい → 開く → 数字を打つ → 保存」の流れが完成し、日常的に続けやすくなる。
