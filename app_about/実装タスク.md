# 貯めログ 実装タスク

更新日: 2026-03-12

この文書は、`frame.md` と `REQUIREMENTS.md` と `DB設計.md` と `API設計.md` をもとに、実装作業を分解したタスク一覧です。
MVP を最後まで通すことを優先し、依存関係順に並べます。

## 1. 実装方針

- 先に土台を固める
- 次に認証とセットアップ
- 次に口座と記録
- 次に画面集約であるホームと進捗
- その後に管理機能
- 追加機能は最後

## 2. Phase 0: 基盤整備

### 2.1 リポジトリ初期構成

- React + Vite + TypeScript の初期化
- Hono API サーバー初期化
- Prisma 初期化
- ESLint / Prettier または Biome 方針確定
- `src/pages`
- `src/components`
- `src/lib`
- `src/server`
- `prisma`

完了条件:

- フロントと API がローカルで起動
- Prisma が DB 接続できる

### 2.2 共通基盤

- 環境変数読込
- API クライアント
- エラーハンドリング
- 認証コンテキスト
- ルーティング枠組み
- PC レイアウト
- モバイルレイアウト

完了条件:

- 未ログイン状態で画面遷移の骨組みが動く

- `GET /api/analysis`
- `POST /api/analysis/generate`
- 月選択
- 再生成

- `POST /api/goals/:id/classify-visual`

- フォールバックは `other/generic`
- 手動修正時は `visualLocked = true`
- 画像専用テキストも同時に解決、またはアセット辞書から引く

## 14. MVP 完了条件

以下が一連で動けば MVP 完了とみなす。

1. 管理者がセットアップできる
2. 管理者が招待を作れる
3. 招待ユーザーが登録できる
4. 一般ユーザーが初期設定できる
5. 口座を作れる
6. 収入、支出、貯金、移動を記録できる
7. 家計簿で履歴を見られる
8. 目標を作れて進捗が見られる
9. ホームで進捗画像つきの注目目標が見られる
