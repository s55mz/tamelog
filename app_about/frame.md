## 2. アプリ全体像

### 2-1. アプリの役割

「貯めログ」は、家計簿アプリというより、`記録を続けること` と `貯金目標を達成すること` を支援するアプリです。

特に次の行動を短い導線で回す設計になっています。

- 収入 / 支出 / 貯金を記録する
- 口座残高を把握する
- 貯金目標を作る、進める
- 衝動買いを 24 時間保留する
- AI に相談する
- 月次の支出傾向を AI で振り返る

### 2-2. 想定ユーザー

- 一般ユーザー
  - 家計を記録したい人
  - 貯金目標を達成したい人
  - 衝動買いを減らしたい人
- 管理者
  - 初期セットアップを行う人
  - 招待リンクを発行する人
  - OpenAI / SMTP / アプリ URL 等を設定する人

## 3. 全体状態遷移

### 3-1. アプリ起動時の大きな分岐

1. 未インストール
   - `SetupWizard`
2. インストール済み / 未ログイン
   - `LoginPage`
3. ログイン済み / 個人セットアップ未完了
   - `UserSetupWizard`
4. ログイン済み / セットアップ完了
   - 通常アプリ本体

### 3-2. ざっくり遷移図

```text
アプリ起動
  ↓
setup/status
  ├─ 未導入 → SetupWizard
  └─ 導入済み
       ├─ 未ログイン → LoginPage
       └─ ログイン済み
            ├─ setupCompleted = false → UserSetupWizard
            └─ setupCompleted = true → MainApp
```

## 7. 主要導線

## 7-1. 初回導入導線

```text
未導入
  → セットアップ
  → 管理者作成
  → インストール完了
  → ログイン
```

## 7-2. 一般ユーザー登録導線

```text
管理者が招待作成
  → 招待URL配布
  → RegisterPage
  → UserSetupWizard
  → ホーム
```

## 7-3. 毎日の利用導線

```text
ホーム
  → 記録
  → 家計簿で振り返り
  → 目標 / 進捗確認
```

## 7-4. 目標達成導線

```text
目標作成
  → 記録画面で「貯金」を入力
  → 目標に紐付け
  → 進捗 / ホームで確認
```

## 7-5. 衝動買い抑制導線

```text
衝動買いチェックに登録
  → 24時間待つ
  → 買う / やめる
  → 履歴へ
```

## 7-6. 管理導線

```text
招待管理
  → 招待作成
  → 管理者画面で設定更新
  → システム状況確認
```

```text

+----------------------------------+
| ステップカード                   |
+----------------------------------+
```

   - アプリの使い方概要

## 9. コンテンツ設計の特徴

### 9-1. 画面ごとの役割が明確

- ホーム: 今日やることを見る
- 記録: すぐ入力する
- 家計簿: 履歴を振り返る
- 目標: モチベーションを維持する
- 進捗: 数字の傾向を見る
- AI: 相談する

### 9-2. 1 画面 1 目的に寄せている

- 記録画面は入力に集中
- 家計簿は一覧確認に集中
- 目標画面は目標カード閲覧に集中

### 9-3. ADHD フレンドリーな要素

- 1 操作が短い
- カード中心で視線移動が少ない
- 今日のミッションがある
- 衝動買い対策が独立している
- AI の説明が短文前提
