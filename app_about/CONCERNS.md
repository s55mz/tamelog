# 貯めログ 残課題

更新日: 2026-03-12

この文書は、`frame.md` と `REQUIREMENTS.md` に反映し切った後でも残る課題だけを管理します。
2026-03-12 時点では、仕様上の大きな未確定事項は解消済みです。

## 1. 現時点で残している課題

- JWT の保存方式は v1 では LocalStorage としたが、将来 HttpOnly Cookie へ移行する余地は残る
- Web Push は v1 範囲外にしたため、通知要件は将来追加時に再定義が必要
- Raspberry Pi 本番運用は可能だが、正式な標準構成はまだ固定していない

## 2. 今回解消した論点

- セットアップは 5 ステップに統一
- タイムゾーンは JST 固定に統一
- `Goal.currentAmount` は廃止
- 口座移動モデル名は `AccountTransfer` に統一
- 招待はメールアドレス固定、1 回利用、手動失効可に確定
- 記録編集は種別変更まで許可する方針に確定
- 口座削除は記録が残る場合不可に確定
- カテゴリは収入用と支出用を分離
- 通知は v1 ではメール通知のみ
- AI 相談履歴は保存しない
- 管理者は AI 相談本文を閲覧不可
- 本番で DB 初期化は不可
