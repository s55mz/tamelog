# 貯めログ — ワイヤーフレーム

テーマ：**夜の帳簿 (Yoru no Chobo)** — 深夜のチャコールに、ミント+コーラル+ゴールドの3色アクセント。
和紙の温かみを持つオフホワイトの文字。Noto Serif JP でヒーロー数字を表示。

---

## カラーシステム

```
背景  --bg        #0F1118   (深夜)
カード --bg-1     #171C28
高め  --bg-2      #1E2435
ホバー --bg-3     #252B3E
境界  --line      rgba(255,255,255,0.07)
文字  --text      #EBE5D9   (温かみのあるオフホワイト)
補助  --text-2    #8A90AA
薄め  --text-3    #525870
━━━━━━━━━━━━━━━━━━
収入  --jade      #4EE28C   (ミントグリーン)
支出  --coral     #FF6475   (コーラルレッド)
貯金  --amber     #FFBE55   (ウォームゴールド)
移動  --sky       #5BAAFF   (スカイブルー)
```

---

## タイポグラフィ

```
表示用 (金額・ロゴ): Noto Serif JP  — 太く、力強く
本文 (UI全般)     : Noto Sans JP   — 読みやすく、親しみやすく
等幅 (コード等)   : IBM Plex Mono
```

## コンポーネント仕様

### ボタン種別

```
[  ログイン  ]   btn--fill   : bg jade, text bg
[  キャンセル  ] btn--out    : border jade, text jade
[  削除       ]  btn--danger : border coral, text coral
[  詳細 →     ]  btn--ghost  : no border, text text-2
```

```
[収入]  badge--in   : jade bg-dim, text jade
[支出]  badge--out  : coral bg-dim, text coral
[貯金]  badge--save : amber bg-dim, text amber
```
